# 日本史 文化史 暗記帳

共通テスト対策の日本史・文化史（原始〜戦後）の暗記問題サイト。

https://morihayashi-juku.github.io/nihonshi/

- `data.js` … 問題データ（時代ID|種類|問題|答え）
- `index.html` … アプリ本体
- `seibutsu/index.html` … 高校生物 暗記帳（高校生物ゼロから講座）。トップページの「ほかの暗記帳」からリンク
- `kagaku/` … 化学 無機・有機 暗記帳（共通テスト対策）。トップページの「ほかの暗記帳」からリンク
  - `index.html` … アプリ本体（一問一答・4択・入力・一覧）
  - `data-muki.js` / `data-yuuki.js` … 問題データ（単元ID|種類|問題|答え、別解は／で区切る）
